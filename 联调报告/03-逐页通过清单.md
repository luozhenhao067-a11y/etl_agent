## 三、权限按钮核验

| 角色 / 页面 | 可见操作 | 判定 |
|---|---|---|
| Maker `/connections` | 新建连接、筛选、测试、编辑、分页 | 符合 Maker 可写 |
| Checker1 `/connections` | 筛选、分页；无新建/测试/编辑 | 符合只读 |
| Checker1 / Checker2 `/runs/preparations` | 提交决策；无 Commit | 符合审批职责 |
| Ops `/runs/preparations` | 提交执行（二次确认） | 符合 Commit 权限 |
| Ops `/runs/executions` | 查询、刷新、取消运行（终态禁用） | 符合 Ops 权限 |
| Checker2 `/governance/benchmark` | 触发评测 | 符合仅 Checker2 |
| Auditor `/governance/benchmark` | 无操作按钮 | 符合只读 |

强制校验（不依赖按钮隐藏）：
- 401 无效用户显示“会话已失效”，不加载业务数据。
- 403 非成员显示“无访问权限”。
- 自批 `APR-403`、审批槽冲突 `APR-409` 由后端返回，前端展示错误。
- 503 不显示成功提示，不写假数据。

## 四、页面问题结论

- J-01（API-07 multipart）、J-03（切换 Run 残留快照）、J-04（stale 渲染失败）、J-06（API-02 未知参数 `q`）已修复并复测。
- J-05 不是后端缺陷：`HARNESS_NOT_READY` 仅内部使用，公开响应使用领域 503 码；口径写入契约附录 A（已按 Spec 对齐）。
- J-07～J-09、J-11 为已登记的契约/产品待确认项，页面按“空态 + 待确认”处理；其中 P-26、P-19/P-35 标记非阻塞。
- 所有页面均未使用前端聚合替代缺失接口；`VITE_USE_MOCK=false` 时 mock 不接管请求。
