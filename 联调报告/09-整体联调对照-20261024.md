## 五、环境边界与等价性说明

- **PostgreSQL / Redis 未启动，`harness/.env` 留空（按约定人工填写）**：kernel 模式实机联调（真库 + 真 Redis 原子防重放）暂不可执行。内核模式启动即 fail-fast（`HARNESS=kernel` 需 `STORAGE=postgres` + `DATABASE_URL`/`REDIS_URL`/签名密钥），不静默降级。
- 等价覆盖：`harness/tests/` 210 项测试以 SQLite StaticPool + fakeredis + 真 Ed25519 种子覆盖 Commit 原子事务、令牌签发/绑定/单次消费、Replay Guard、Worker 状态机、派发重试/死信、哈希链验证（`external_entries==0`）等内核全链路；丢失令牌、伪造令牌、桩引擎、传输失败等 fail-closed 路径均有断言。
- stub 模式实机冒烟（第二节）证明 18 端点对外口径不回归。环境就绪后按 `harness/.env` 填写即可切换 kernel 模式复测。
