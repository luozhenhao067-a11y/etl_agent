# 生产级 ETL-Agent 数据集成平台 PRD 需求文档

> **文档依据**：本文档完全基于《项目实战》原文 **“2.8 生产级 ETL-Agent 数据集成平台”** 整理，不扩展原文未定义的产品范围。  
> **整理说明**：原文未定义需求优先级，本文不擅自设置 P0/P1；如需排期，建议由项目组另行评审。  
> **产品名称**：生产级 ETL-Agent 数据集成平台  
> **产品形态**：Vue 前端控制台 + FastAPI 控制面服务 + Celery 异步 Worker/Beat + PostgreSQL/Redis + SeaTunnel Zeta 集成 + Benchmark 评测体系。

---

## 1. 背景与产品目标

### 1.1 背景

企业数据集成场景中，ETL 需求从自然语言到可执行配置、从生成到审批、从执行到质量治理，存在安全边界不清、审批职责混用、配置不可追溯、执行副作用不可控、运行异常难诊断等问题。原文要求建设一个**生产级 ETL-Agent 控制面平台**，结合 **LangGraph** 与**不可绕过的 Agent Harness 内核**，实现受管、可审计、可审批、可回滚的数据集成闭环。

### 1.2 产品目标【原文 2.8】

实现面向企业数据集成场景的生产级 ETL-Agent 控制面平台，覆盖：

1. 自然语言需求解析；
2. 受管异构元数据安全探查；
3. 结构化 EtlPlan 与 SeaTunnel HOCON 配置生成；
4. 确定性门禁校验；
5. 不可变制品版本化；
6. 四眼职责审批（Maker-Checker）；
7. 单次 Capability 令牌授权；
8. Celery 异步调度与 SeaTunnel 执行；
9. 运行监督与质量契约分流闭环。

### 1.3 交付形式【原文 2.8】

提供可运行：

- Vue 前端控制台；
- FastAPI 控制面服务；
- Celery 异步 Worker/Beat 服务；
- PostgreSQL/Redis 数据库脚本；
- SeaTunnel Zeta 集成配置；
- 仿真评测 Benchmark 数据集；
- 接口说明文档；
- 完整业务演示链路。

## 2. 产品范围

### 2.1 In Scope【原文 2.8.1】

| 范围域 | 需求内容 |
|---|---|

| 数据源与元数据探查 | 异构数据库接入（MySQL、PostgreSQL、Oracle、Doris、ClickHouse）；文件与 API 数据源接入（CSV、Excel、JSON、Parquet、S3/MinIO、REST API）；只读元数据安全探查（Schema、字段类型、近似统计、脱敏样本采样） |

| Harness 安全内核 | 策略决策点（PDP / P0-P3 风险评级）、`prepare → approve → commit` 三阶段执行协议、四眼原则独立审批（Maker-Checker）、Ed25519 签名短时单次 Capability 令牌、防重放 Guard、事务 Outbox 可靠投递、证据账本（Evidence Ledger）追加与防篡改 |
| 数据面执行与治理 | Celery 异步任务执行、SeaTunnel 引擎对接、影子表与原子 Swap 发布、错误数据分流与质量契约（QualityContract）、运行监督（行数/字节/时长/放大比/拒绝率预算监控）、任务取消与回滚 |
| 评测与安全进化 | 分层仿真（L0 静态注入、L1 模拟故障、L2 真实链路）、版本化 Benchmark 自动化评测、受控安全进化闭环 |

### 2.2 Out of Scope【PRD整理，依据原文边界】

原文未要求控制面直接搬运海量业务数据；明确“控制面不直连搬运海量业务数据”，数据面搬运由 Apache SeaTunnel 负责。本文档不额外定义原文之外的业务功能。

## 3. 用户角色与权限

### 3.1 角色定义【原文 2.8.2】

| 角色 | 职责 |
|---|---|
| 数据工程师（申请人 / Maker） | 登记数据源连接、发起元数据探查、输入自然语言需求、调试并生成 Pipeline 候选方案、提交不可变版本与审批申请 |
| 数据审批人（Checker 1） | 审查需求描述、Schema 映射、脱敏前后对比、质量规则与 DAG 结构，执行数据维度审批 |
| 安全审批人（Checker 2） | 审查资源范围、数据敏感分级、执行预算、Secret 引用与回滚方案，执行安全维度审批；管理 Benchmark 与安全进化 |
| 系统操作员 | 在所有审批通过后执行 Commit 操作、触发受管执行、监控运行状态、执行任务暂停/取消/回滚与凭据轮转 |
| 审计人员 | 查看执行历史、审计事件、签名证据账本、数据质量报告与 Benchmark 评测大盘 |

### 3.2 强制职责分离规则【原文 2.8.2】

1. 申请人禁止自批。
2. 高风险操作禁止同一人占用多个审批职责槽。
3. 系统需在项目内配置独立的数据工程师、数据审批人与安全审批人，并强制拦截申请人自批与职责混用【原文 2.8.11】。

## 4. 核心业务流程

### 4.1 端到端需求生成与受管执行流程【原文 2.8.10】

1. 数据工程师配置源库（MySQL）与目标库（Doris）连接，生成受管元数据 Profile。
2. 数据工程师在 Studio 输入自然语言 ETL 需求。
3. LangGraph 状态机解析需求；必要信息缺失时触发中断提问；工程师补充回答后从 Checkpoint 恢复。
4. 模型生成结构化 EtlPlan 与 SeaTunnel HOCON 配置，并通过语法编译器与确定性门禁校验。
5. 冻结生成不可变 PipelineVersion，并计算 SHA256 摘要。
6. 调用 Prepare 接口生成准备单；PDP 计算风险等级并分配数据审批人与安全审批人职责槽。
7. 数据审批人与安全审批人分别完成独立审批（四眼原则）。
8. 操作员调用 Commit 接口；服务端校验审批与指纹后签发单次 Capability，写入 Outbox。
9. Celery Worker 消费任务，验签后调用 SeaTunnel 执行搬运。
10. SeaTunnel 将有效数据写入影子表，错误数据写入错误表；监督引擎持续监控预算。
11. 质量报告通过后，Doris 执行原子 Swap 发布正式表；关键链路生成防篡改证据账本。

### 4.2 任务失败诊断与安全回滚流程【原文 2.8.10】

1. 执行异常或监督超限时触发中断，记录失败快照。
2. 诊断服务提取错误堆栈，生成可解释根因说明与修复建议。
3. 操作员发起回滚指令；Harness 验证权限后调用受管清理逻辑恢复原状态。

## 6. 核心协议与业务规则

### 6.1 控制面与数据面分离【原文 2.8.4】

- FastAPI + LangGraph + Celery + PostgreSQL 负责控制面治理。
- Apache SeaTunnel 负责数据面搬运。
- 控制面不直连搬运海量业务数据。

### 6.2 三层状态隔离规则【原文 2.8.4】

| 状态层 | 内容 |
|---|---|
| 对话状态（Conversation State） | 记录自然语言交互历史 |
| Agent 状态机（Workflow State） | LangGraph 管理澄清、生成、门禁校验与有限修复，通过 PostgreSQL Checkpoint 跨请求持久化与恢复 |
| 底层执行状态（Execution State） | 记录实际任务运行实例（ExecutionRun）、SeaTunnel 作业 ID 与指标 |

### 6.3 `prepare → approve → commit` 三阶段执行协议【原文 2.8.4】

| 阶段 | 规则 |
|---|---|
| Prepare | 推导输入指纹、资源范围、影响范围、数据分级、运行预算与回滚方案，冻结生成 Preparation 单，不产生外部副作用 |
| Approve | 具名审批人基于冻结事实执行独立审批，强制四眼原则与职责分离 |
| Commit | 服务端重新比对指纹与审批事实，签发 Ed25519 签名短时单次 Capability 令牌，经 Tool Broker 在同一 PostgreSQL 事务中原子创建 ExecutionRun 与 Outbox 投递命令 |

### 6.4 防重放与单次能力规则【原文 2.8.4】

- Capability 令牌绑定工具、主体、环境与制品指纹。
- 有效期 5 分钟。
- 由 Replay Guard 保证只能消费一次。

### 6.5 质量分流与原子发布规则【原文 2.8.4】

- 有效数据写入影子表。
- 错误数据按质量契约分流至专用错误表并打标错误码。
- 校验通过后通过原子 Swap（如 Doris `REPLACE TABLE ... swap=true`）将影子表替换为正式表。

### 6.6 质量契约（QualityContract）【原文 2.8.9】

1. 声明字段级清洗过滤规则（如非空校验、正数校验、邮箱脱敏格式）。
2. 配置错误数据流向与错误码标签（ErrorCode）。
3. 数据面执行时将未命中规则的数据分流写入错误表，记录原始值与违规原因。

### 6.7 运行时监督契约（RuntimeSupervisionContract）【原文 2.8.9】

1. 冻结最大读取行数、最大写入字节数、最大执行时长预算。
2. 监控输出放大比与错误拒绝率阈值。
3. 越线时按策略触发预警、硬中断（Kill Job）或隔离告警。

## 7. 数据模型需求

| 表名 | 关键字段 |

### 7.2 关键数据规则

- `pipeline_versions.is_immutable` 用于标识不可变版本。
- `pipeline_versions.artifact_digest` 用于保存 SHA256 摘要。
- `execution_runs.capability_token_digest` 用于记录 Capability 令牌摘要。
- `audit_events` 需维护 `prev_event_hash` 与 `event_hash`，形成哈希链。
- `runtime_supervision_snapshots` 需保存监督指标、决策与采取动作。

| POST | `/api/v1/approval-requests/{approval_id}/decisions` | 提交具名审批决策（approve / reject） |
| POST | `/api/v1/preparations/{preparation_id}/commit` | 校验审批与指纹，签发 Capability 并原子提交执行 |
| GET | `/api/v1/execution-runs/{id}` | 查询任务执行状态、指标与质量报告 |
| POST | `/api/v1/execution-runs/{id}/cancel` | 请求取消运行中作业 |
| POST | `/api/v1/execution-runs/{id}/rollback` | 触发受管影子表回滚与清理 |
| POST | `/api/v1/benchmarks/run` | 触发自动化安全与准确率 Benchmark 评测 |

### 8.2 接口安全规则

- Commit 接口必须校验审批与指纹。
- Capability 令牌必须由服务端签发，绑定工具、主体、环境与制品指纹，5 分钟内有效且只能消费一次。
- 所有副作用执行必须经 Tool Broker，拦截未授权调用与重放请求。

## 9. 非功能与安全需求

| 类别 | 需求 |
|---|---|
| 认证鉴权 | 用户认证鉴权、多租户项目管理、项目成员与角色分配【2.8.1】 |
| 凭据安全 | 敏感凭据受管加密存储，使用 SecretProvider / Vault KV v2【2.8.1】 |
| 审批安全 | 四眼原则、申请人禁止自批、高风险操作禁止同一人占用多个审批职责槽【2.8.2】 |
| 执行安全 | `prepare → approve → commit` 三阶段协议；Tool Broker 为副作用唯一出口；Replay Guard 防重放【2.8.4、2.8.6】 |
| 审计防篡改 | Evidence Ledger 维护关键事件哈希链与签名检查点【2.8.6】 |
| 数据脱敏 | 元数据探查展示脱敏样本，全链路无敏感明文泄露【2.8.11】 |
| 运行监督 | 监控记录数、字节数、时长、输出放大比与拒绝率，触发预警或硬中断【2.8.6、2.8.9】 |
| 可靠投递 | Transactional Outbox 保证本地业务事实与 Worker 任务投递原子落库【2.8.6】 |
| 可恢复性 | LangGraph Checkpoint 跨请求持久化与恢复【2.8.4】 |

## 10. 验收标准

依据原文 2.8.11，系统需满足：

1. 能在项目内配置独立的数据工程师、数据审批人与安全审批人，系统强制拦截申请人自批与职责混用。
2. 能接入异构数据库与文件数据源，完成安全元数据探查并展示脱敏样本，系统全链路无敏感明文泄露。
3. 能通过自然语言需求触发 LangGraph 状态机生成 EtlPlan 与 SeaTunnel HOCON 配置，并在缺少参数时正确中断与恢复。
4. 能通过确定性门禁对生成的 Pipeline 配置进行语法与 Schema 校验，通过后生成不可变版本摘要。
5. 能完整执行 `prepare → approve → commit` 三阶段协议，成功生成准备单、完成四眼审批并签发单次 Capability。
6. 能通过 Celery Worker 调度 SeaTunnel 完成数据搬运，实现有效数据影子表写入与错误数据质量分流。
7. 能在数据达标后通过原子 Swap 完成正式表发布，并在运行中心查看实时指标与质量报告。
8. 能在超预算或异常情况下触发运行时监督与可解释根因诊断，并支持受管回滚。
9. 能运行自动化 Benchmark 评测集，输出准确率与安全拦截率评测报告。
